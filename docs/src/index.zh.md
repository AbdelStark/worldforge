# WorldForge

**面向物理 AI 系统的可测试世界模型工作流。**

WorldForge 是一个面向可测试物理 AI 世界模型工作流的 Python 集成层。它为各类提供方、打分模型、
具身策略以及媒体生成器赋予明确的能力契约，并在此基础上提供世界状态、规划、评估、基准测试、诊断，
以及面向本地实验与适配器开发的命令行工具。
