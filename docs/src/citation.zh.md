# 引用

如果 WorldForge 对您的研究或开源工作有所帮助，请引用仓库元数据：

```yaml
cff-version: 1.2.0
title: WorldForge
version: 0.5.0
repository-code: https://github.com/AbdelStark/worldforge
url: https://abdelstark.github.io/worldforge/
license: MIT
```

机器可读的引用文件为
[CITATION.cff](https://github.com/AbdelStark/worldforge/blob/main/CITATION.cff)。
