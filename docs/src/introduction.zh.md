# 简介

WorldForge 是一个面向可测试物理 AI 世界模型工作流的 Python 集成层。它为提供方、打分模型、具身策略和媒体生成器提供明确的能力契约，并在此基础上提供世界状态、规划、评估、基准测试、诊断以及用于本地实验和适配器开发的 CLI 工具。

本项目围绕严格的提供方边界构建：

- 预测模型通过 `predict` 向前推演状态
- 打分模型通过 `score` 对候选动作序列进行排序
- 具身策略通过 `policy` 提出动作块
- 辅助模型仅在直接实现该操作时才暴露 `embed`

这确保了提供方语义的真实性。JEPA 代价模型不会被视为视频生成器；VLA 机器人策略不会被视为预测动力学模型。

WorldForge 面向正在构建提供方适配器、本地物理 AI 实验、世界模型规划循环、评估运行时以及可测试原型的 Python 开发者。它不是一个托管控制平面，也不拥有检查点、机器人运行时、生产遥测或持久化多写入存储。
