# 采用案例研究

本节收集来自团队的 WorldForge 公开采用故事，这些团队在集成、评估套件、
提供方包、机器人工作流或宿主应用中使用了 WorldForge。

目前尚无提交的案例研究。如需贡献，请将
[`_template.md`](./_template.md) 复制到本目录并使用描述性文件名，
或提交一个"Adoption Story"Issue，以便维护者协助完善最终条目。

有价值的案例研究应阐明：

- 谁采用了 WorldForge，或者采用方是否需要保持匿名；
- 使用 WorldForge 的宿主应用或工作流；
- 涉及的 WorldForge 能力、提供方、工件或 CLI 命令；
- 哪些是自定义的，哪些是开箱即用的；
- 哪些方面运行良好；
- 哪些方面使用起来较为繁琐、有所缺失或难以解释；
- 在可以安全分享的前提下，提供公开链接、截图、演讲、论文、仓库或发布说明。

请勿包含密钥、私有提示词、凭据、已签名 URL、专有数据集、检查点字节、
宿主本地路径或私有机器人/控制器细节。如果采用故事需要匿名处理，
请说明哪些内容可以公开发布，并将私有细节排除在 Pull Request 之外。
