# Evidence-Based Completion

## Activation Contract

Use this skill when:
- Defining "done" criteria for tasks
- Proving completion with evidence
- Setting up completion verification
- Reviewing completion evidence
- Troubleshooting completion issues

## Hard Rules

- Public contract, tests, docs, and agent context must all agree
- Evidence is command-backed, not claimed
- Run the command, show output, attach artifacts
- No claims without proof
- Every change needs evidence artifacts

## Decision Gates

| Need | Action |
|------|--------|
| Define done | Establish evidence-based criteria |
| Prove completion | Run commands and collect evidence |
| Verify evidence | Check evidence artifacts |
| Review evidence | Validate completeness |

## Execution Steps

1. Define evidence-based done criteria for each change type
2. Run commands to generate evidence
3. Collect evidence artifacts
4. Validate evidence completeness
5. Attach evidence to PR
6. Review and verify evidence

## Output Contract

- Evidence-based done criteria
- Evidence artifacts
- Validated evidence
- Completed PR with evidence
